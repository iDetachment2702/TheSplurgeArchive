# 💸 TheSplurgeArchive（散財行為記録保管所）

ローカルのエディタでMarkdownを書き、GitHub Pagesにデプロイするブログ。

なんらかの限界がくるまではバックエンドも他のクラウドサービスも使わずにやっていくコンセプト。

## 実装済みの機能

- **記事表示**: Markdown形式で書かれた記事をレンダリング
- **タグ機能**: 記事を複数のタグで分類・フィルタリング
- **月別アーカイブ**: 記事を月別に整理して閲覧
- **レスポンシブデザイン**: モバイルとデスクトップの両方に対応
- **圧縮配信**: 記事をgzip圧縮してファイルサイズを削減
- **静的サイト生成**: ビルド時に記事を処理し、高速な静的サイトを生成
- **リンクカードの生成**: 単独でURLを記述したときにリンクカードを生成

## 技術構成

- フロントエンド: React + TypeScript
- ビルドツール: Vite
- スタイリング: Tailwind CSS
- ルーティング: React Router
- 状態管理: Jotai
- Markdownパース: marked + DOMPurify
- テスト: Vitest + React Testing Library
